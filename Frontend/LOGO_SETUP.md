# Logo Setup for TEST BANK

## Instructions

1. **Add your logo file** to the `Frontend/public/` folder
   - Name it: `test-bank-logo.png` (or any image format)
   - Recommended size: 40-50px height for navbar display
   - The logo should be transparent or light-colored since the navbar has a dark emerald background

2. **The navbar will automatically use the logo** from `public/test-bank-logo.png`

Alt text and title are set to "TEST BANK" for accessibility.

## Logo specifications for best results:
- Format: PNG with transparency (recommended)
- Height: 40px (will scale proportionally)
- Style: Should match your gold/emerald theme for consistency
